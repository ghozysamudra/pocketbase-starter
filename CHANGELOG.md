# Changelog

All notable changes to this project are documented in this file.

## 0.0.2 - 2026-10-23

### Changed

- Upgraded the stack to SvelteKit 3, Svelte 5.57, Vite 8.3, Vitest 5, Tailwind CSS 4.3, and PocketBase SDK 0.28.
- Migrated to the SvelteKit 3 `#lib` alias and `$app/env/public` environment API.
- Pointed the app at the public PocketBase `v0.40.6-dev` instance by default.

### Added

- App version and GitHub repository link in the home and dashboard footers.

## 0.0.1

- Initial PocketBase Starter release.
